# 🚀 Nexa - Your Community. Your Space. Your Way.

Nexa is a modern social and community platform for chatting, gaming communities, friends, profiles, discovery, and messaging.

## Features

✨ **Modern Social Platform**
- User profiles with customizable banners and avatars
- Friend system with requests and management
- Direct messaging with group chat support
- Online status and custom status

🎮 **Community System**
- Create and manage communities
- Organize communication with rooms
- Role-based access control
- Community rules and moderation
- Events and announcements

🌍 **Discovery**
- Trending communities
- Personalized recommendations
- Browse by category
- Global search

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Zustand

## Getting Started

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Local Development

> **Note:** This is a frontend mock prototype. There is no backend or external service. All data is mocked in `src/data/mockData.ts`.

### Commands

```bash
# Install dependencies
npm install

# Start development server (http://localhost:5173)
npm run dev

# Type-check and build for production
npm run build

# Preview the production build
npm run preview
```

### Mock Login

Use any email with an `@` sign and any password of 8+ characters to log in. The app uses mock user data defined in `src/data/mockData.ts`.
